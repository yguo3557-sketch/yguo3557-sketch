# 郑孝天 · Trader.Z

经济金融背景，白天看盘，晚上写工具。
这里放我做出来、也愿意给别人用的东西。

## 项目

**炮王识别指南** — 一份完整的反面案例拆解
把一个人的话术 / 人设 / 系统逐条拆开：13 条聊天原话标注「他在干嘛 → 识别信号 → 你怎么接」，18 条红旗模式 + 聊天检测八步 SOP + 命令行扫描脚本。
把聊天记录贴给 AI，说一句「帮我分析这段聊天记录，他是真心的吗」，它走完八步流程给你一份带风险分的报告。
→ [yguo3557-sketch/paowang-guide](https://github.com/yguo3557-sketch/paowang-guide)

**MiMo Agent Orchestrator** — 多模型 Agent 调度框架
基于 LangGraph，动态路由 GPT-4o / Claude / DeepSeek，三个专职 Agent（市场分析 / 风险评估 / 策略生成），含成本分层与定时服务。
→ [yguo3557-sketch/mimo-agent-orchestrator](https://github.com/yguo3557-sketch/mimo-agent-orchestrator)
